TotalCashPro — Hostinger Deploy (public_html structure)
=======================================================

Repo: https://github.com/Asad2512-dev/totalcashpro
Branch: main

Recommended structure (easy git pull):

~/domains/totalcashpro.com/public_html/   <-- FULL Laravel project
  .git/
  .htaccess        (routes all traffic to /public)
  index.php
  app/
  public/
  artisan
  composer.json
  .env

Daily update:
  cd ~/domains/totalcashpro.com/public_html
  git pull origin main
  composer install --no-dev --optimize-autoloader
  php artisan migrate --force
  php artisan config:cache
