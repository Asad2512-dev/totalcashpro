# Business Admin Guide

## Dashboard
Real-time metrics from your database: today's cash-up status, attendance, inventory alerts and recent activity.

## Setup wizard
Eight-step onboarding: business → branch → currency/VAT → cash drawer → staff invites → supplier → finish. Skip anytime; resume from Settings.

## Modules

| Module | Purpose |
|--------|---------|
| Cash Up | Daily till reconciliation |
| Cash History | Past cash-ups |
| Clock In | PIN-based staff clock |
| Attendance | Edit and review hours |
| Staff | Create, suspend, reset passwords |
| HR | Approve leave and shift swaps |
| Rota | Weekly shift planning |
| Inventory | Categories, items, stock counts |
| Suppliers | Suppliers and invoices |
| Purchase Orders | PO → receive → finance sync |
| Finance | Income, expenses, bills, payroll |
| Recurring Bills | Auto-generate bill templates |
| Petty Cash | Floats and small expenses |
| Cash Drawers | Till opening balances |
| CRM | Customers, notes, visit history |
| Reports | 13 report types, CSV export |
| Branches | Multi-branch management |
| Settings | Organisation preferences |

## Branch filter
Use the topbar branch selector to scope dashboard, cash-up and reports.

## Notifications
Bell icon shows in-app alerts. Email preferences on Account Security.

## Billing
After trial, select a plan. Stripe checkout coming in v1.1 — selection is saved locally until then.
